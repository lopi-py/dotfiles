# Clarify Request

Use the smallest coherent set of decision-focused questions that establishes a reliable direction.

## Workflow

1. Inspect targeted evidence and conventions that may resolve uncertainty.
2. Identify the unresolved choices that meaningfully affect the outcome or constraints.
3. If the evidence supports a clear interpretation, proceed without asking.
4. Otherwise, batch the questions needed to resolve those choices. Use concrete options when useful, recommend reasonable defaults, and briefly explain important consequences.

Consider outcome, scope, technical constraints, inputs, and success criteria when relevant. Ask only about important decisions needed for the requested work.
